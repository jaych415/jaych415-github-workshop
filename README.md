# Average Workshop API

## Team Members

- Jayesh Chaudhary

## Project Description

A web application that accepts numeric input and calculates an average.

## Technologies Used

- Python
- FastAPI
- uv
- pytest
- mypy
- ruff
- Docker

## Setup Instructions

1. Install uv.
2. Run `uv sync`.
3. Start the development server with `uv run fastapi dev app/main.py`.
4. Open `/docs` in your browser to view the API documentation.
